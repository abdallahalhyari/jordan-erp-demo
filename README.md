# Jordan ERP — web demo

Live demo: https://abdallahalhyari.github.io/jordan-erp-demo/

Bilingual (Arabic / English) ERP prototype for a Jordanian beverage distributor: sales, purchasing,
inventory and vans, cheques, accounting and simulated JoFotara e-invoicing.

- All data is generated demo data held in the browser; nothing is saved or sent anywhere.
- JoFotara is simulated only.
- Switch roles from the user menu (top corner) to see what each role can do.

This repository contains only the built web app.
